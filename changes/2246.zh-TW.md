- **任務看板：專案、主任務和子任務，以及你的確認（#2246）。** Fleet › Tasks 現在是一個看板。打開是你的專案和各自的
  完成度，以及待你處理的事：做完等你**確認**或**退回**的工作、等你**回覆**的卡住的卡。專案頁是它的主任務依狀態分欄的
  看板，可以拖曳移動卡片、依負責人篩選，每張主任務都能展開子任務。卡片打開後每個欄位都能編輯，也看得到留言、進度紀錄
  和變更歷史；你開始編輯之後 instance 才寫入的話，你的修改會被拒絕，不會蓋掉對方的。在網頁上開的主任務做完會停下來等你
  確認，而且只有在網頁登入的人能確認：instance 對這種卡的 `task` `done` 會把它改成 `review`，只帶 web token 的請求也照
  instance 的規則處理。以前的任務保留原本的 id，放在**未分類**；保留期限也不再清掉專案裡已完成的卡片。`task` 工具的 `id` 可以用卡號（`M-3`），
  不加篩選的清單也會列出 `review` 的卡。詳見
  [功能說明](features.zh-TW.md#在網頁上fleet--tasks)。
